# 📱 Aplicativo de Localização de Orfanatos

Este é um projeto desenvolvido durante a faculdade com o objetivo de **aproximar pessoas de orfanatos próximos à sua localização** e mostrar formas de ajudar essas instituições.  
A ideia central é utilizar a tecnologia para **gerar impacto social positivo**, facilitando a conexão entre quem deseja contribuir e quem precisa de apoio.

---

## 🚀 Funcionalidades
- Exibição de orfanatos próximos no mapa.
- Detalhes de cada orfanato (endereço, informações e como ajudar).
- Interface intuitiva e acessível.

---

## 🛠️ Tecnologias Utilizadas
- **Kotlin**
- **Jetpack Compose**
- **Google Maps API**
- **Android Studio**
